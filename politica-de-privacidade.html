Política de Privacidade

Última atualização: 22 de abril de 2026 Conforme LGPD — Lei nº 13.709/2018
Esta Política descreve como o escritório Camilo & Pessanha Advocacia coleta, usa, armazena e protege seus dados pessoais ao utilizar este site.

Camilo & Pessanha Advocacia (CP Advocacia)

WhatsApp: (21) 97274-2109

2. Dados que Coletamos

2.1 Dados fornecidos diretamente pelo usuário

Ao preencher o formulário de contato disponível no site, coletamos:

  • Nome completo — campo obrigatório
  • Telefone / WhatsApp — campo obrigatório
  • Área jurídica de interesse — seleção entre: Criminal (24h), Previdenciário, Trabalhista, Inventário, Família ou Outro
  • Descrição do caso — campo de texto livre, opcional

O envio do formulário exige o consentimento expresso do usuário via checkbox com a seguinte declaração: "Concordo com o tratamento dos meus dados conforme a LGPD apenas para retorno do contato."

2.2 Dados coletados automaticamente

Ao navegar pelo site, podem ser coletados automaticamente dados técnicos como: endereço IP, tipo de navegador, sistema operacional, páginas visitadas, tempo de permanência e origem do acesso. Esses dados são coletados via cookies conforme detalhado na seção 4.

3. Finalidade do Tratamento

Os dados coletados são utilizados exclusivamente para as seguintes finalidades:

  • Retorno de contato: responder às mensagens enviadas pelo formulário;
  • Atendimento jurídico inicial: identificar a área de interesse para direcionar o contato ao sócio responsável;
  • Melhoria do site: análise de uso para aprimorar a experiência de navegação (mediante consentimento para cookies analíticos);
  • Publicidade: exibição de anúncios relevantes em outras plataformas (apenas se o usuário consentir com cookies de publicidade).

4. Cookies

Este site utiliza um sistema de gerenciamento de cookies com as seguintes categorias:

Categoria Descrição Obrigatório
Necessário Essenciais ao funcionamento do site. Armazenam preferências de consentimento (chave: site_cookie_consent no localStorage). Sem eles o site não funciona corretamente. Sim
Funcional Permitem funcionalidades de compartilhamento em mídias sociais e recursos de terceiros integrados ao site. Não
Analítico Coletam dados sobre como os visitantes interagem com o site (páginas visitadas, taxa de rejeição, origem do tráfego). Não
Desempenho Analisam índices de carregamento e desempenho técnico do site para melhorar a experiência do visitante. Não
Publicidade Permitem a exibição de anúncios personalizados com base em páginas visitadas anteriormente em outras plataformas. Não

O usuário pode alterar suas preferências de cookies a qualquer momento clicando no link "Cookies" no rodapé do site.

A preferência de consentimento é armazenada localmente no dispositivo do usuário por até 365 dias.

5. Compartilhamento de Dados

O escritório não vende, aluga ou comercializa dados pessoais de usuários a terceiros.

Este site utiliza serviços de terceiros que podem processar dados técnicos de navegação:

  • Google Maps / Google Fonts: carregamento de mapas e tipografias via servidores do Google;
  • WhatsApp (Meta): ao clicar nos links de WhatsApp, o usuário é redirecionado para a plataforma da Meta;
  • Instagram (Meta): links para o perfil institucional do escritório na plataforma.

Cada um desses serviços possui sua própria política de privacidade, sobre a qual o escritório não tem controle.

6. Seus Direitos como Titular (LGPD)

Nos termos da Lei Geral de Proteção de Dados (Lei nº 13.709/2018), você tem direito a:

  • Confirmação da existência de tratamento de seus dados;
  • Acesso aos dados pessoais que mantemos sobre você;
  • Correção de dados incompletos, inexatos ou desatualizados;
  • Anonimização, bloqueio ou eliminação de dados desnecessários ou excessivos;
  • Portabilidade dos dados a outro fornecedor de serviço;
  • Eliminação dos dados tratados com seu consentimento;
  • Revogação do consentimento a qualquer momento, sem prejuízo da legalidade dos tratamentos anteriores.

Para exercer qualquer desses direitos, entre em contato pelos canais indicados na seção 9.

7. Segurança dos Dados

Adotamos medidas técnicas e organizacionais adequadas para proteger seus dados contra acesso não autorizado, perda, alteração ou divulgação indevida, incluindo:

  • Transmissão de dados via protocolo HTTPS (quando o site estiver hospedado com certificado SSL);
  • Armazenamento de preferências de consentimento apenas localmente no dispositivo do usuário (localStorage);
  • Acesso restrito às informações enviadas pelo formulário de contato.

8. Retenção de Dados

Os dados do formulário de contato são mantidos pelo tempo necessário para responder à solicitação e pelo prazo legal aplicável. Após esse período, os dados são eliminados de forma segura.

As preferências de cookies armazenadas no dispositivo do usuário expiram automaticamente após 365 dias ou podem ser removidas a qualquer momento via configurações do navegador.

9. Menores de Idade

Este site não é direcionado a menores de 18 anos e não coleta intencionalmente dados pessoais de crianças ou adolescentes. Caso identifiquemos coleta inadvertida de dados de menores, os dados serão imediatamente eliminados.

10. Alterações desta Política

Esta Política pode ser atualizada periodicamente. Alterações relevantes serão comunicadas por aviso no site. A data de "Última atualização" no topo deste documento indica a versão vigente.
